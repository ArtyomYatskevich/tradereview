# TradeReview

TradeReview is a trading journal for web, iOS and Android: https://tradereview.app/

## Features

- Auto Sync for MT5, cTrader, TradeLocker, IBKR, Alpaca and eToro
- CSV importer for other brokers
- Review queue and notebook for every trade
- Insights and a Discipline score
- AI chat and an MCP server to query your journal from AI tools
